## Publish with GitHub Pages
This is a static website; the main page is `index.html`.

Repository: https://github.com/yunuspatty96/GenAI_Workshop_Personal_Website.github.io

To publish from the `main` branch, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages may take several minutes to publish.

Suggested project URL:
https://yunuspatty96.github.io/GenAI_Workshop_Personal_Website.github.io/

The site is built with plain HTML, CSS, and JavaScript. No build step or backend is required.
